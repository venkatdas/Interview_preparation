# Combinatorics — Interview Questions

Answer out loud first, then open the model answer. Back to [the topic README](../README.md).

### 1. What is the difference between a permutation and a combination? Give a one-line test to decide which you need.
<details><summary>Model answer</summary>

A permutation counts ordered selections, a combination unordered ones. Test: "if I swap two chosen items, is it a different outcome?" Yes → permutation (P(n,k) = n!/(n−k)!), no → combination (C(n,k) = P(n,k)/k!). Dividing by k! removes the k! orderings of each chosen set.
</details>

### 2. Why can't you compute C(n, k) as factorial(n) / (factorial(k) * factorial(n−k)) in JavaScript for n = 30?
<details><summary>Model answer</summary>

Numbers are IEEE doubles, exact only up to 2^53 − 1 ≈ 9e15. 30! ≈ 2.65e32, so the factorials are already rounded and the quotient is off. Use the multiplicative formula with BigInt (`res = res * (n−k+i) / i`, exact at every step) or Pascal's rule (additions only).
</details>

### 3. Explain the 2^53 trap in modular arithmetic and two ways to avoid it.
<details><summary>Model answer</summary>

Under mod 1e9+7, residues are up to ~1e9 and their product up to ~1e18, past 2^53, so `(a*b) % MOD` drops low bits silently. Fixes: (1) BigInt: `Number(BigInt(a) * BigInt(b) % BigInt(MOD))`, simple but slower; (2) split multiplication: write b = bHi·2^16 + bLo, then `((a*bHi % m) * 65536 + a*bLo) % m` where every partial product stays below 2^47. (`Math.imul` does not help: it is 32-bit.)
</details>

### 4. How do you answer 10^5 queries of C(n, k) mod 1e9+7 with n ≤ 10^6?
<details><summary>Model answer</summary>

Precompute fact[0..N] and invFact[0..N]. invFact[N] = fact[N]^(p−2) by Fermat (p prime); then invFact[i−1] = invFact[i]·i walking down. Each query is fact[n]·invFact[k]·invFact[n−k], O(1). Build cost O(N + log p). Requires p > N, otherwise fact[n] ≡ 0.
</details>

### 5. State stars and bars and solve: how many non-negative integer solutions to a + b + c + d = 10?
<details><summary>Model answer</summary>

n identical items into k distinct bins (empty allowed): C(n+k−1, k−1). Here C(13, 3) = 286. With each variable ≥ 1: C(n−1, k−1) = C(9, 3) = 84.
</details>

### 6. Name four things counted by Catalan numbers and give the formula.
<details><summary>Model answer</summary>

Cat(n) = C(2n, n)/(n+1): 1, 1, 2, 5, 14, 42. Counts BST shapes with n keys, balanced parentheses strings with n pairs, Dyck paths that never cross the diagonal, triangulations of an (n+2)-gon, full parenthesizations of n+1 factors. Recurrence Cat(n) = Σ Cat(i)·Cat(n−1−i) — "choose a root/first match, two independent sides".
</details>

### 7. Derive the derangement recurrence.
<details><summary>Model answer</summary>

Item 1 goes to position j (n−1 choices). If item j goes to position 1, the other n−2 items form a derangement: D(n−2). If not, treat "position 1" as item j's forbidden spot: a derangement of n−1 items, D(n−1). So D(n) = (n−1)(D(n−1) + D(n−2)), D(0)=1, D(1)=0. D(n)/n! → 1/e.
</details>

### 8. Explain inclusion–exclusion and when it becomes too slow.
<details><summary>Model answer</summary>

Count objects with none of k bad properties as Σ over subsets S of (−1)^|S|·N(S), where N(S) counts objects having at least the properties in S. It corrects the over-subtraction of overlaps. There are 2^k subsets, so it's fine for k ≤ ~20, or when terms depend only on |S| (then k+1 terms times C(k, j)).
</details>

### 9. Walk through next permutation on [1, 3, 5, 4, 2].
<details><summary>Model answer</summary>

Rightmost ascent: 3 < 5 at index 1. Rightmost element bigger than 3: 4 (index 3). Swap → [1,4,5,3,2]. Reverse the suffix after index 1 → [1,4,2,3,5]. O(n), O(1) space; works with duplicates if comparisons are ≥ / ≤.
</details>

### 10. How do you find the k-th permutation without generating the first k−1?
<details><summary>Model answer</summary>

Factorial number system. With m items left, each first choice covers (m−1)! permutations, so the index of the next item is ⌊rank/(m−1)!⌋ (0-indexed rank), then rank %= (m−1)!. O(n^2) with array splicing, O(n log n) with a Fenwick tree for "the idx-th unused item".
</details>

### 11. When should you choose a counting DP instead of a formula?
<details><summary>Model answer</summary>

When constraints interact in a way a formula can't express cleanly: obstacles in a grid, "a song can repeat only after k others", forbidden adjacent letters. Define a state capturing everything the future depends on, ensure each object is generated by exactly one path, and add the mod. Use the formula (if any) as a cross-check.
</details>

### 12. What does the pigeonhole principle let you conclude, and give a coding example.
<details><summary>Model answer</summary>

If more than n items go into n boxes, a box holds two. It proves existence. Examples: Find the Duplicate Number (n+1 values in [1, n]); among n+1 prefix sums mod n, two are equal → a subarray sum divisible by n exists.
</details>

### 13. Why does "count arrangements of a word with repeated letters" use division, and how do you divide mod p?
<details><summary>Model answer</summary>

n! counts every arrangement c1!·c2!·… times (swapping identical letters gives the same string), so divide by that product. Mod a prime p, division by x is multiplication by x^(p−2) (Fermat), or use precomputed invFact[c].
</details>

### 14. You computed a count mod 1e9+7 and it comes out negative after inclusion–exclusion. Why, and how to fix?
<details><summary>Model answer</summary>

JavaScript `%` keeps the sign of the dividend, so `(a − b) % p` can be negative. Normalize: `((a − b) % p + p) % p`.
</details>
