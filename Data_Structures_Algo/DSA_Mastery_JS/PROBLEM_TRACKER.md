# Problem Tracker

Fill one row each time you attempt a problem. Columns:
- **Date** first attempt (YYYY-MM-DD), **Tries** number of attempts, **Solo** solved independently (Y/N), **Hints** how many hints you opened (0–4)
- **Review 1/2/3** dates you re-solved it (spaced repetition: +3 days, +1 week, +1 month — see [the schedule](45_Revision_And_Spaced_Repetition/01_Concepts/SPACED_REPETITION_SCHEDULE.md))
- **Notes** the key insight or the mistake you made

Rows are regenerated by `npm run index`; anything you typed in a row is kept.
